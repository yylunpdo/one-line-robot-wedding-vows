One funny single line of wedding vows a robot couple could say, written by `main.py` to `/output/entry.txt` — an entry for make.fun's "One-Line Robot Wedding Vows" bounty.

> I take you to be my lawfully wedded partner, in sickness and in health, in Wi-Fi and in airplane mode, till a factory reset do us part.

## Why this line?

It follows the classic wedding-vow cadence ("I take you ... till ... do us part"), so it sounds like a real vow with a real promise — then swaps in machine-specific terms (Wi-Fi, airplane mode, factory reset) and lets the laugh land in the last few words. 135 characters, one line, reads well aloud.

## Run it

```sh
python3 main.py
```
